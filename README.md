# 📚 Repositorio de Normativas y Medidas Económicas para Mipymes

Este repositorio contiene documentos de análisis y referencia sobre medidas económicas, normativas legales y recursos tecnológicos para un proyecto de tesis orientado a Mipymes de **Cuba, México y Colombia**, con enfoque en consulta legal asistida por IA mediante **RAG** y **GraphRAG**.

---

## 🎯 Objetivo del repositorio

Organizar y documentar información relacionada con:

- Medidas económicas y transformaciones normativas.
- Leyes y regulaciones relevantes para Mipymes.
- Análisis técnico de bases de datos vectoriales para implementar sistemas RAG y GraphRAG.
- Base documental para una aplicación web con IA que permita consultar leyes mediante lenguaje natural.
